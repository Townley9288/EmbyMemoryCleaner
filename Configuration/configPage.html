Memory Cleaner

周期性触发完整 GC + LOH 压缩 + 工作集释放，缓解 Emby 长时间运行导致的内存膨胀。

源自 sjtuross/StrmAssistant 的 MemoryCleaner 模块，独立 GUID，与 StrmAssistant / StrmAssistantPro 不冲突。

勾选后按下方间隔自动执行 GC + LOH 压缩 + 工作集释放。
范围 1 - 120，默认 30。内存增长较快可填 5 - 15，低频维护可填 60。
检测到任何会话正在播放（包含转码、直出、直传）时则跳过本次定时清理，避免 GC STW 引起播放卡顿。手动「立即清理」不受此设置影响。
勾选后，「在播跳过」只在存在转码会话时生效；直出/直传播放仍会执行清理（GC 极短暂，通常无感）。
填 0 表示不启用阈值。例如填 2048 表示进程 RSS 超过 2 GB 才执行 GC，避免无意义的清理。
